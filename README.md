# wazuh-siem-home-lab

## What I built
I deployed Wazuh, an open-source security monitoring platform, as a virtual machine in VirtualBox on my Windows laptop. I connected my laptop to it as an agent, so its security events are sent to the Wazuh server and shown in a dashboard.

## What I tested
I generated failed login attempts on my laptop and looked for the alerts they created in the dashboard.
